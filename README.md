# JLPT N2 十七週複習網站（2026）

個人備考用的靜態網站。複習期間 2026-08-09 至 2026-12-05（17 週），考試日 2026-12-06。

## 日常操作

```bash
npm run dev
```

開啟 http://localhost:5180 —— 網站會依照台北當地日期，自動判斷今天是第幾週、第幾天。

其他指令：

| 指令 | 用途 |
|---|---|
| `npm run dev` | 開發伺服器（改檔案會自動重新整理） |
| `npm run test` | 執行所有測試 |
| `npm run test:watch` | 邊改邊測 |
| `npm run validate:content` | 只檢查 `content/` 的 JSON 有沒有寫錯 |
| `npm run typecheck` | 只檢查型別 |
| `npm run build` | 產生 `dist/`，可上傳到 GitHub Pages |
| `npm run preview` | 預覽 build 出來的結果 |

## 用手機測試

```bash
npm run dev -- --host
```

終端機會印出一個 `http://192.168.x.x:5180` 的網址，手機連同一個 Wi-Fi 就能開。
用來確認手機上的版面與日文發音是否正常。

## 日文發音

發音用的是瀏覽器內建的語音合成，**離線可用、不需要網路、沒有音檔授權問題**。
這台 Mac 上有 Kyoko、Hattori、O-Ren 三個本機日文語音，可在設定頁切換與調整語速。

兩個限制要記得：

- **不要拿它記重音（ピッチアクセント）。** TTS 的語調不完全可靠。
- **不能取代正式聽解。** 語速與自然度跟真實考題有差距，它適合跟讀語彙與例句。

若瀏覽器沒有日文語音，發音按鈕會整顆不顯示（不會留一個按了沒反應的按鈕）。
iPhone 可在「設定 → 輔助使用 → 朗讀內容 → 聲音」新增日文語音。

**作答中刻意不提供發音**——漢字読み的題目若能唸出題幹，等於直接把答案講出來。
發音只出現在語彙、文法例句、交卷後的逐題檢討，以及錯題本。

## 預覽任意日期

網址加上 `?today=YYYY-MM-DD` 就能看到那一天的畫面，方便確認邊界情況：

- <http://localhost:5180/#/?today=2026-08-08> — 開始前的準備頁
- <http://localhost:5180/#/?today=2026-08-09> — 第 1 週 Day 1
- <http://localhost:5180/#/?today=2026-12-05> — 第 17 週最後一天
- <http://localhost:5180/#/?today=2026-12-06> — 考試當日頁
- <http://localhost:5180/#/?today=2026-12-07> — 備考完成摘要

畫面上方會出現黃色的「預覽模式」提示，點「回到今天」即可回復。

## 專案結構

```
content/          學習內容（JSON）。之後新增內容只改這裡，不需要動程式。
src/
  lib/date/       日期與週次計算。全站唯一的日期邏輯來源。
  lib/course/     十七週課綱骨架（每週主題、七天排法）。
  lib/progress/   進度存取（尚未建置）
  lib/scoring/    計分與弱點分析（尚未建置）
  components/     共用元件
  pages/          各頁面
  styles/
    tokens.css    ★ 全站色彩、間距、字級。想調外觀改這個檔案。
    japanese.css  日文排版與振假名
```

## 兩個重要的設計原則

**1. 日期邏輯只在一個地方。**
`src/lib/date/courseCalendar.ts` 是唯一計算週次的檔案，而且只有 `getTodayInTaipei()`
會讀取系統時間，其餘都是純函式。時區固定為 Asia/Taipei，出國也不會算錯。

**2. 十七週共用同一個頁面元件。**
`WeekDetail.tsx` 一個檔案服務全部 17 週；要改某一週的內容，改
`src/lib/course/outline.ts` 或 `content/` 裡的資料，不要複製頁面。

## 每週的七天節奏

| Day | 星期 | 內容 |
|---|---|---|
| 1 | 日 | 語彙・漢字 |
| 2 | 一 | 文法・辨析 |
| 3 | 二 | 讀解 |
| 4 | 三 | 聽解 |
| 5 | 四 | 混合複習（含前幾週錯題） |
| 6 | 五 | 本週複習測驗 |
| 7 | 六 | 彈性補做（不計入完成率） |

例外週：第 1 週（診斷）、第 14 週（分科模擬）、第 15／16 週（完整模擬考，排在週六）、
第 17 週（最終整理，不排模擬考）。

### 關於 `npm audit` 的警告

`react-router` 目前有一則 high 等級警告（RSC Mode CSRF Bypass）。
該問題只影響 React Server Components 模式下的 route action。
本專案是純靜態 SPA：沒有伺服器、沒有 RSC、沒有 route action，因此不受影響，
不需要為此降版。
