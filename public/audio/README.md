# 聽解音檔

自備的聽解音檔放這裡，然後在 `content/listening/wXX.json` 用 `audioSrc` 指向它：

```json
{
  "id": "lis-w05-01",
  "audioSrc": "./audio/w05-01.mp3",
  "transcript": ["すみません、会議室{かいぎしつ}はどちらですか。"],
  "source": { "type": "original", "label": "自己錄音" }
}
```

沒有 `audioSrc` 時，網站會自動退回用瀏覽器內建的語音合成朗讀 `ttsScript`；
連語音合成都沒有時，就顯示原文讓你自己讀。三段降級，任何環境都不會變成死路。

## 音檔可以從哪來

- **自己錄。** 最單純，也沒有任何授權問題。
- **公有領域或開放授權的音源。** 使用時在 `source` 欄位註明來源與授權。
- **官方公開的問題例。** 日本國際交流基金與日本國際教育支援協會有公開部分試題與音檔，
  **使用前請自行確認授權條款**，並在 `source` 註明。

## 不可以放的東西

- 市售教材附的 CD／下載音檔（新完全マスター、TRY!、日本語総まとめ 等）
- 付費題庫或線上課程的音訊
- 來源不明、無法確認授權的檔案

這個網站是個人備考用途。內容一律保留來源欄位，是為了日後真的需要時
能說清楚每一份素材從哪裡來。
